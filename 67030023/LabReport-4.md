## 3. แบบฟอร์มรายงานผลการชันสูตรทางวิศวกรรม (Engineering Forensic Incident Report)

```text
================================================================================
                    ENGINEERING FORENSIC INCIDENT REPORT
================================================================================
1. รหัสนักศึกษา / ผู้รายงาน: 67030023
2. กรณีศึกษาข้อผิดพลาด (Fault Case No.): [ ] Case 1   [ ] Case 2   [X] Case 3   [ ] Case 4
3. อาการที่ตรวจพบทางกายภาพ (Observed Physical Symptoms):
   หน้าจอ OLED แสดงผลข้อความ "HELLO WORLD" และ "ID: 67030023" กลับหัว 180 องศา (Upside-down) 
   และสลับด้านซ้าย-ขวา (Mirrored Image) โดยโซนสีเหลืองไปปรากฏอยู่ด้านล่างแทนที่จะอยู่ด้านบน

4. สมมติฐานและการทดสอบเบื้องต้น (Hypothesis):
   สงสัยว่าค่าการตั้งค่าสแกนทิศทางพิกเซล (Segment Remap) และทิศทางสแกนแถว (COM Output Scan Direction) 
   ในชิป SSD1306 ถูกกำหนดไว้เป็นค่า Default จากโรงงาน (0xA0 และ 0xC0) ประกอบกับการติดตั้งแผงจอ OLED 
   กลับหัวทางกายภาพจากกระบวนการผลิต

5. หลักฐานที่ตรวจพบจากโค้ดหรือหน่วยความจำ (Discovered Forensic Evidence):
- บรรทัดของโค้ดที่เกิดปัญหา: ในฟังก์ชัน oled_spi_init() หรือ Magic Initialization Sequence 
  ที่ไม่มีการส่งคำสั่ง 0xA1 (Set Segment Remap Column 127 mapped to SEG0) 
  และ 0xC8 (Set COM Output Scan Direction Decreasing Mode)
- ค่าใน Memory Dump หรือ Opcode ที่ผิดพลาด: ค่า Register Command 0xA0 (Column Address 0 mapped to SEG0) 
  และ 0xC0 (Normal Scan Direction COM0 to COM[N-1])

6. มาตรการแก้ไขและผลการยืนยันความถูกต้อง (Corrective Action & Verification):
   เพิ่มคำสั่งปรับตั้งทิศทางสแกนลงในชุด Magic Initialization Sequence:
   - ส่งคำสั่ง oled_send_cmd(0xA1); เพื่อกลับทิศทาง Segment Remap จากซ้ายไปขวา
   - ส่งคำสั่ง oled_send_cmd(0xC8); เพื่อกลับทิศทาง COM Scan Direction จากล่างขึ้นบน
   ผลการยืนยัน: หน้าจอ OLED แสดงผลตัวอักษรตั้งตรงปกติ 180 องศา ข้อความอ่านได้ถูกต้อง 
   และโซนสีเหลืองกลับขึ้นไปอยู่ด้านบนสุดของหน้าจอตามดีไซน์กายภาพ
================================================================================
4. คำถามท้ายการทดลองเพื่อการประเมินผล (Review Questions)ข้อ 1: หากสายสัญญาณ SCK (GPIO 18) หลุดออกจาก Breadboard ผลการทำงานของหน้าจอ OLED จะแสดงอาการอย่างไร และเพราะเหตุใด?คำตอบ:หน้าจอ OLED จะ ค้างอยู่ที่สถานะล่าสุด หรือดับสนิท (ไม่มีการอัปเดตใดๆ บนจอ) เนื่องจาก:สัญญาณ SCK (SPI Serial Clock) ทำหน้าที่เป็นจังหวะสัญญาณนาฬิกาในการสีกิฟต์ (Shift) บิตข้อมูลเข้าสู่ Shift Register ของชิปคอนโทรลเลอร์ SSD1306เมื่อสาย SCK หลุด ชิป SSD1306 จะไม่ได้รับ pulse สัญญาณนาฬิกา ทำให้ไม่สามารถรับ latch ข้อมูลพิกเซลหรือคำสั่งใดๆ ผ่านสาย MOSI (D1) ได้อีกต่อไป ส่งผลให้กระบวนการส่งถ่ายข้อมูลหยุดชะงักลงทันทีข้อ 2: ในการวิเคราะห์บั๊กเชิงนิติวิทยาศาสตร์ เหตุใดการทำ Hex Dump หน่วยความจำ Framebuffer จึงเป็นหลักฐานที่น่าเชื่อถือกว่าการมองด้วยสายตาเปล่าบนหน้าจอ?คำตอบ:แยกแยะปัญหาระหว่าง Software กับ Hardware ได้อย่างเด็ดขาด: การตรวจสอบ Hex Dump ใน s_oled_buffer (RAM บน ESP32) ช่วยยืนยันว่าอัลกอริทึม Bitwise Manipulation และการประมวลผลวาดภาพทางฝั่งซอฟต์แวร์มีความถูกต้องหรือไม่ข้ามข้อจำกัดของอุปกรณ์แสดงผลทางกายภาพ: หากสายไฟหลุด ชิป SSD1306 เสีย หรือส่งคำสั่งตั้งค่าหน้าจอผิด (เช่น ปัญหา Mirror/Flip) หน้าจออาจแสดงผลผิดพลาดหรือดับสนิท แต่มองด้วยตาเปล่าจะไม่สามารถระบุได้ว่าผิดที่โค้ดวาดภาพหรือผิดที่ฮาร์ดแวร์ การทำ Hex Dump จะเป็นหลักฐานดิจิทัลที่พิสูจน์ความถูกต้องของบิตข้อมูล $1$ และ $0$ ในหน่วยความจำได้แม่นยำ 100%
